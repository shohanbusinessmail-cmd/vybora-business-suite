# Licensing Specification — Vybora Business Suite

Lifetime, one-time-purchase, fully offline licensing. Ed25519 signatures. The app can
only VERIFY; only the owner-only License Generator can SIGN.

## 1. Trust model
- Owner generates an Ed25519 keypair offline at first run of the License Generator
  (key ceremony, `KEY_CEREMONY.md`). Private key is stored encrypted (passphrase,
  argon2id-derived key + AES-256-GCM via cryptography) in the owner's private data
  directory. **Never** in Git, CI, installers, logs, or customer machines.
- The matching **public** key is committed at `src/vybora/licensing/public_key.pem`
  (public material is safe) and embedded in release builds. Until the owner completes
  the ceremony, the file contains a placeholder marker and the app is
  **unprovisioned → activation fails closed** (LIC-09).
- Customer machines never receive the generator or private key.

## 2. Machine fingerprint (privacy-conscious)
`fingerprint = SHA-256( "vybora-fp-v1|" + joined normalized components )`, hex.
Windows components (best-effort, order-stable):
1. Registry `HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid`
2. SMBIOS UUID (`wmic csproduct get uuid` / PowerShell CIM fallback)
3. System volume serial number
Each component is trimmed/uppercased; missing components are omitted (at least one
required). Only the hash is stored/transmitted — never raw IDs, never personal data.
Linux (dev/test): `/etc/machine-id`. Limits: major hardware changes alter the
fingerprint → controlled reissue/transfer by owner. No security guarantee against a
determined local attacker (offline software can be patched); this is documented.

## 3. Activation request file (`.vbr`, JSON)
```json
{ "format": "vybora-activation-request-v1", "product": "vybora-business-suite",
  "machine_fingerprint": "<64 hex>", "app_version": "x.y.z", "created_at": "ISO-8601" }
```
Generated by the app (Bengali UI), saved anywhere (USB), sent to owner out-of-band.

## 4. License file (`.vbl`, JSON)
Canonical payload (sorted keys, compact separators, UTF-8, no BOM):
```json
{ "format": "vybora-license-v1", "license_id": "UUID", "product": "vybora-business-suite",
  "business_name": "...", "business_id": "owner-assigned", "edition": "lifetime",
  "issued_at": "ISO-8601", "lifetime": true, "machine_fingerprint": "<64 hex>",
  "license_version": 1, "transfer_of": null }
```
File = `{ "payload": <canonical-JSON-string>, "signature": "<base64 Ed25519>" }`.
Verification: parse → re-canonicalize payload → verify signature over the canonical
bytes → check format/product/fingerprint/lifetime/fields → store activated state in
`license_metadata` + license file copy in data dir. Every startup re-verifies the
stored license offline (no network). Tampered payload/signature/wrong machine → reject
with Bengali message. Reissue: new license with `transfer_of` = old license_id; old
license recorded as transferred in generator history (offline revocation list is
owner-side administrative only — instant remote revocation is impossible by design).

## 5. Generator features (owner-only)
Admin passphrase gate; key ceremony; import request; business name/id inputs; sign;
preview; export `.vbl`; local history (SQLite, owner machine); verify any license;
reissue/transfer; revocation record (administrative). Built as a separate EXE
(PyInstaller) — **never** part of the customer installer or public releases.

## 6. Failure modes (all fail-closed, Bengali messages)
missing license · unprovisioned public key · bad signature · modified payload · wrong
product · wrong fingerprint · malformed JSON · unsupported format version.

## 7. Key rotation
If the signing key is compromised: owner generates a new keypair, publishes an app
update embedding the new public key, reissues licenses to customers. Old licenses
become invalid after update. Procedure: `KEY_CEREMONY.md`.

## 8. Honest limitations
Offline licensing cannot provide instant remote revocation or stop a determined
attacker with full local access. Machine binding is a deterrent, not DRM-grade
protection. Lifetime usage rights are independent of internet availability.
